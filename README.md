# Konsultacje

Aplikacja do rezerwacji konsultacji psychologicznych, tworzona na zajęciach
„Projektowanie aplikacji webowych” (SWPS).

## Uruchomienie

    python -m venv .venv
    pip install -r requirements.txt
    python hello.py
    ## Uruchomienie

    python -m venv .venv
    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver
